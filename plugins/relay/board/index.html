How to use relay

YOU only you can type it · ASK AI say it in plain words, Claude does it · AUTO happens by itself · GITHUB outside Claude Code · REQUIRED OPTIONAL

  1. Open Claude Code in your project folder. YOU REQUIRED
  2. First time in a project: type /relay:setup-project, then say yes. YOU REQUIREDOnce per project. Claude finds your checks and shows the plan before it writes anything.
  3. Work as usual. Ask for changes. ASK AI AUTOEach time Claude says it is done, relay runs your checks and sends it back if one fails. Nothing to do.
  4. Happy with it? Type /relay:ship. YOU OPTIONALClaude reviews, then asks before commit, push and PR. Or just ask: "commit this and open a PR".
  5. Merge the PR in GitHub. GITHUB REQUIREDThe only step outside Claude Code. Relay never merges.
  6. Watch this board. AUTOPurple: go answer that session. Amber: a check failed, Claude is fixing it. Green: ready to ship.

Installed or updated relay? Type /reload-plugins in each open session. Full guide with pictures: docs/guide.html in the relay-agents repo.
